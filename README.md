# FREE-LIVO project page

Project page for the ICRA 2027 submission:

> FREE-LIVO: Physically Decoupled Yet Tightly Coupled LiDAR-Inertial-Visual Odometry

The site is intentionally framework-free. To preview it locally, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

Research figures live in `assets/`; all content is derived from the ICRA 2027 manuscript repository.
